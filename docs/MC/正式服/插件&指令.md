## 二、测试服常用指令手册  
**更新日期**：2025年07月09日（实时同步）  
**适用范围**：正式服

### 常用指令列表  

> 注：`<>` 为必填项
> 
> 表格模板：`| `` | `` |  | `` |  |`

| 指令格式 | 指令缩写 | 功能说明 | 使用示例 | 注意事项 |  
|:-:|:-:|:-:|:-:|:-:|
| `/reg <密码> <密码>` | `` | 注册并设置服内账号密码 | `/reg 123456 123456` | 密码需符合强度要求，设置后需通过 `/login` 手动登录 |  
| `/login <密码>` | `/l` | 登录服内账号 | `/login 123456` | 需先通过`/reg`注册并设置密码 |  
| `/tpa <玩家ID>` | `` | 请求传送至目标玩家 | `/tpa zhengddzz`| 需要目标玩家通过请求才能到达其所在的位置 |
| `/tphere <玩家名称>` | `` | 请求玩家传送到你身边 | `/tphere zhengddzz` | 需要目标玩家通过请求才能将其传送到你的位置 |
| `/warp <传送点>` | `` | 传送到传送点 | `/warp 1` |  |
| `/setwarp <传送点>` | `` | 设置传送点 | `/setwarp 1` |  |
| `/delwarp <传送点>` | `` | 删除传送点 | `/delwarp 1` |  |
| `/home <家>` | `` | 传送到家 | `/home 1` |  |
| `/homes` | `` | 列出你设置的家 | `/home` |  |
| `/sethome <家>` | `` | 设置家 | `/sethome 1` |  |
| `/setdefaulthome <家>` | `` | 设置默认的家 | `/setdefaulthome 1` |  |
| `/delhome <家>` | `` | 删除家 | `/delhome 1` |  |
| `/back` | `` | 传送到上一次的位置 | `/back` |  |
| `/money` | `` | 查询余额 | `/money` |  |
| `/money <玩家>` | `` | 查询`<玩家>`余额 | `/money zhengddzz` |  |
| `/pay <玩家> <金额>` | `` | 转账给`<玩家><金额>` | `/pay zhengddzz 100` |  |
| `/balancetop` | `` | 查询余额排行榜 | `/balancetop` |  |
| `/xconomy help` | `/xc help` | 查看xconomy插件帮助 | `/xconomy help` |  |
| `/residence` | `/res` | 查看residence插件帮助 | `/residence` |  |
