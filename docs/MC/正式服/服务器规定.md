# 正式服规定

## 一、账号管理规范
1. 账号所有权归服务器，玩家仅拥有使用权，账号信息（含ID、密码）需妥善保管
2. 密码管理：
   - 支持自助修改密码（需验证原密码）
   - 不提供密码找回服务，遗忘密码需重新注册账号
   - 有要求密码强度
3. 账号限制：
   - 单IP最多绑定3个账号，超出部分将限制登录

## 二、游戏行为规范
### （一）一般违规（处罚：游戏内禁言1-12小时）
1. 公共频道刷屏（1分钟内发送6条及以上重复内容）
2. 轻微破坏他人建筑（拆除≤10个方块且可修复）
3. 恶意阻挡他人通行、抢夺公共资源点（如挂机霸占刷怪笼）
4. 发布与游戏无关的广告（非商业性质）

### （二）严重违规（处罚：账号封禁3-15天）
1. 使用轻度辅助工具（自动走路、自动挖矿脚本等非破坏平衡工具）
2. 故意破坏他人核心建筑（主城设施、玩家标志性建筑）
3. 以欺诈手段获取他人物品（虚假交易、冒充管理员索要装备）
4. 在聊天频道发表辱骂、歧视性言论（含谐音、拼音替代）

### （三）红线违规（处罚：永久封禁账号+IP封禁）
1. 使用破坏平衡的外挂（透视、飞天、秒杀、物品复制等）
2. 实施炸服行为（利用漏洞攻击服务器、上传恶意数据包）
3. 进行现实货币交易（含虚拟物品、账号买卖、代练收费）
4. 发布违法违规内容（涉黄赌毒、政治敏感信息等）

## 三、建筑与领地规则
1. 领地限制：
   - 出生地附近500范围无法建领地
2. 建筑规范：
   - 禁止建造违背公序良俗的建筑（色情、暴力、恐怖元素）
   - 距离他人领地30格内建造需征得对方同意
3. 领地回收：连续14天未登录，无传承权限的领地将被系统回收

## 四、管理员权限规范
1. 禁止利用权限为本人或他人谋取私利（刷物品、改数据、特殊权限）
2. 执行处罚需保留截图或视频证据（存放于管理后台，保存期30天）
3. 违规处理：
   - 轻度违规：暂停权限7天，公开道歉
   - 严重违规：永久移除管理团队，封禁关联账号，公示违规详情

## 五、补充说明
1. 所有处罚由系统日志+人工审核判定，结果通过QQ群和文档展示
2. 对处罚有异议可在3天内提交申诉（联系管理员），逾期不予受理
